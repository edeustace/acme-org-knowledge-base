# Acme Org — who we are

Acme Org builds **Acme Product**, the platform our customers use to run their
day-to-day operations. This knowledge base is the shared source of truth for how we
work and why the product is shaped the way it is.

## Teams

| Team | Area |
|---|---|
| **Platform** | Core services, infrastructure, SRE |
| **Product** | Web + API surface, UX, design |
| **Data** | Pipelines, analytics, ML |
| **Quality** | Testing, release gates, QA |

## Ways of working

- We write things down. Answers live here, not in chat history.
- Anything important goes through an [RFC](../rfcs/README.md) before the code lands.
- We review each other's work via pull requests; in-review ideas get commented on
  *in Lens*, on the exact line they're about.

## Contact

Ownership lives in each doc's front-matter or an `owner` heading. If something's
unclear, leave a comment on the page — someone on that team will pick it up.
